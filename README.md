# Wavecon-Telecom-Insights-from-Power-BI-Dashboard
Power BI project analyzing the business impact of Wavecon Telecom’s 5G launch. Tracks post-rollout revenue (-0.5%), active users (-7M), and churn (+1.4M) alongside plan-level performance (P1, P7, P13). Leverages DAX and KPI modeling to provide strategic recommendations for retention, pricing, network coverage, and plan optimization.
